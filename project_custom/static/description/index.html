Dynamic Project Clusters, Groups & Timesheet Customization

Structure projects with Clusters & Groups while dynamically controlling Timesheet fields per group.

Module Overview

By default, Odoo Projects lack multi-level categorization, and custom fields on Timesheets (account.analytic.line) appear globally across all projects. This module provides an end-to-end solution: organizing projects into 2-level categories (Cluster & Group) and dynamically showing/hiding timesheet columns based on the Group assigned to each Project.

Key Features

  • 2-Level Master Data Configuration: Create and manage Master Categories for Clusters and Groups (Groups belong to specific Clusters).
  • Project Form Integration: Assign Cluster and Group directly on the Project form view for enhanced classification and reporting.
  • Dynamic Timesheet Column Control: Configure specific visible fields on the Timesheet model (account.analytic.line) tied to each Group.
  • Smart Filter on Timesheet Tab: When viewing the Timesheet tab inside a Project, the columns dynamically adapt, showing only the fields configured for that Project's active Group.

How It Works

1. Configure Clusters & Groups

Go to Configuration to define your Project Clusters and nested Groups. Map the allowed/required Timesheet fields for each Group.

2. Assign Cluster & Group to Project

On any Project Form (e.g., Project A), select the appropriate Cluster and Group from the header fields.

3. Tailored Timesheet Tab Experience

Switch to the Project's Timesheets tab. The list view instantly adapts, presenting only the specific columns configured for the project's selected Group.
