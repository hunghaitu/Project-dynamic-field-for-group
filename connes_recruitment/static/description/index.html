Dynamic Timesheet Fields by Project Group

Tailor your Timesheet List View dynamically based on tailored Project Groups assignment.

Module Overview

By default, adding custom fields to Odoo Timesheets (account.analytic.line) forces those fields to display globally across all projects and users. This module introduces a granular, flexible solution: dynamically showing or hiding specific timesheet fields based on custom user groups configured per project.

Key Features

  • Custom Field Extensions: Easily manage custom fields on the account.analytic.line (Timesheet) model.
  • Flexible Custom Groups Definition: Dedicated backend configuration model to create and define your own dynamic target groups.
  • Project-Specific Group Assignment: Link specific custom groups directly inside the Project settings.
  • Dynamic List View Filter: Inside any Project's Timesheet tab, clicking the "three dots" option dropdown allows users to select and apply available fields mapped specifically for the current project's active group.

How It Works

1. Define Custom Groups & Fields

Navigate to settings to configure your specialized groups and assign which structural fields on the timesheet line belong to each group.

2. Bind Groups to Projects

Open any Project Form, look for the newly added Group selection field, and assign the proper target group for that specific project scope.

3. Interactive Column Selection

Go to the Project's Timesheet sub-tab. Click the list view's column optional configuration button (the "three dots"). The system dynamically filters and displays only the custom fields authorized for the group assigned to that project.
